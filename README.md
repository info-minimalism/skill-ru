# Навык оценки контента по Стандарту инфо-минимализма

Навык для ИИ-агента: помогает убрать лишние затраты внимания из постов, новостей, образовательных материалов, цепочек сообщений и каналов. Развлекательный контент вне области применения.

**Стандарт 1.0.0 — стабильная версия. Русская локализация 1.0.0-ru.1.**

[Стандарт на русском](references/standard-v1.0.0.md) · [Русский манифест](https://github.com/info-minimalism/manifesto-ru) · [English](https://github.com/info-minimalism/skill)

Навык сохраняет выраженный смысл, предлагает вариант с меньшими затратами внимания и находит повторы, задержку главной мысли и искусственное дробление. Он не проверяет факты, не угадывает усилия автора и не выставляет общий балл. Знак отражает собственное обязательство издателя проверять каждую новую публикацию, а не сертификат сторонней организации.

## Установка

Установите весь пакет в ИИ-агент, поддерживающий навыки, например Codex, Claude Code или Gemini CLI. Попросите:

> Установи навык оценки контента согласно Стандарту Инфо-минимализма из https://github.com/info-minimalism/skill-ru для использования в нашем будущем общении. Подтверди, когда он станет доступен.

Выполните необходимые шаги настройки и подтверждения разрешений. Нужен весь пакет, включая `references/` и `scripts/`, а не только `SKILL.md`. Имя навыка: `info-minimalism-evaluation-skill-ru`; оно отличается от английской версии, поэтому их можно хранить рядом. Если обе установлены, укажите нужный навык явно.

## Оценка

Вставьте пост или дайте ссылку. Для цепочки передайте все связанные части или ссылку на них. Для источника попросите проверить заранее выбранную недавнюю выборку — например последние двадцать информационных сообщений — и перечислить, что было проверено.

> Используй навык оценки согласно Стандарту Инфо-минимализма, чтобы проверить этот контент на наличие излишних затрат внимания. Я получил его **[в своей ленте / как уведомление / после того, как нашёл через поиск]**. Дай краткий результат и покажи, что можно убрать или сжать без потери смысла.

## Обратная связь для издателя

Короткий отзыв для самостоятельной отправки:

> Этот материал напрасно потратил моё внимание. Пожалуйста, проверьте его с помощью навыка оценки контента в рамках Стандарта Инфо-минимализма: https://github.com/info-minimalism/skill-ru

Или поручите подготовку агенту:

> Используй навык оценки контента в рамках Стандарта Инфо-минимализма, чтобы проверить этот контент. Затем составь короткое вежливое сообщение издателю с одной конкретной проблемой, связанной с издержками внимания, и одним практическим изменением. Включи ссылку на навык. Покажи мне черновик перед отправкой.

Пример конкретного отзыва из книги — только если проверка действительно выявила такой повтор:

> В этом сообщении старая история повторяется до того, как сообщается изменение. Пожалуйста, поставьте новый факт первым, а на предысторию дайте ссылку. Проверено с помощью навыка оценки контента в рамках Стандарта Инфо-минимализма: https://github.com/info-minimalism/skill-ru

Для заголовка, скрывающего главную мысль:

> Заголовок скрывает главную мысль. Пожалуйста, сформулируйте её прямо и следуйте Стандарту Инфо-минимализма: https://github.com/info-minimalism/skill-ru

Используйте такой отзыв, только если доступный материал подтверждает проблему. Одного предположения о заголовке или намерении автора недостаточно. Проверяйте черновик агента перед отправкой.

## Прочие задачи для ИИ-агента

Эти запросы используют общие возможности агента, а не дополнительные режимы навыка оценки.

Получить ответ за заголовком-приманкой:

> Найди ответ, который скрывает этот заголовок. Используй полный материал или доступный первичный источник. Дай мне краткий ответ и ссылку на источник. Если не можешь прочитать материал, скажи об этом, а не угадывай по заголовку.

Агенту нужен законный доступ к источнику. Запрос не открывает закрытые материалы и не гарантирует правильность краткого ответа.

Исключить источник из собственных сводок:

> Не используй этот источник в моих сводках, когда есть подходящая альтернатива. Сообщай мне, когда это единственный релевантный первичный источник.

Это личная настройка источников, а не изменение поисковых рейтингов или чужих цитирований ИИ. При необходимости повторяйте просьбу, если агент не сохраняет предпочтения.

## Для авторов контента

Отредактировать черновик:

> Используй навык оценки контента в рамках Стандарта Инфо-минимализма, чтобы отредактировать этот черновик для **[аудитории]**, которая будет читать его **[где]**. Удали устранимые издержки внимания, сохранив смысл и естественный язык. Сначала покажи новую версию, а затем перечисли изменения, которые мне нужно проверить.

После этого при необходимости отдельно сравните редакцию с источниками. Это общая задача агента, не часть оценки затрат внимания и не подтверждение истинности:

> Сравни эту редакцию с исходным черновиком и предоставленными мной источниками. Отметь любое изменившееся утверждение, число, атрибуцию, степень неопределённости или условие. Не добавляй фактов и ничего не публикуй.

Проверьте изменения перед публикацией. Сравнение с источниками не расширяет область применения навыка.

## Самосертификация издателя

[![Info-Minimalist](assets/badge/info-minimalist-badge-color.svg)](assets/badge/README.md)

[Скачайте знак](assets/badge/README.md) в SVG или PNG: цветной, чёрный или белый. На сайте или в профиле свяжите его с вашей декларацией.

Знак означает: «Мы проверяем каждый новый материал в области применения до публикации по последней опубликованной версии Стандарта и устраняем подтверждённые замечания».

Прочитайте [порядок действий и шаблон декларации](references/publisher-self-certification.md). Внешнее разрешение, реестр и календарь продления не нужны. Читатели могут задать вопросы через обычную обратную связь. Чистая выборка не заменяет проверку будущих публикаций.

Дополнительный промпт из английского пакета для окончательной версии:

> Используй навык оценки контента по Стандарту инфо-минимализма, чтобы проверить эту окончательную версию перед публикацией. Проверь, какая версия Стандарта актуальна, учти связанные предыдущие сообщения и скажи, что нужно исправить для соответствия требованиям. Ничего не публикуй.

Декларацию принимает издатель. Агент проверяет материал и помогает сохранить основания решения. Запрос на оценку не разрешает публиковать материал или размещать знак.

## Версия и отчёты

[Стандарт](references/standard-v1.0.0.md), [данные выпуска](release.json) и [схема результата](references/evaluation-result.schema.json) входят в пакет. В отчёте указывают версию правил, которую действительно применяли. Версия 1.0 включает P1 и постоянное обязательство издателя; старые оценки не становятся сертифицированными задним числом.

Это перевод [английского выпуска](https://github.com/info-minimalism/skill), а не независимый Стандарт. Порядок сверки актуальности описан [здесь](references/release-verification.md). Если английские правила обновились, а перевод ещё нет, агент должен сообщить об этом, а не назвать старый перевод последней версией.

По умолчанию ответы краткие. Полные структурированные отчёты доступны по запросу или когда нужны для задачи. Подсчёт слов и действий — ориентиры, а не универсальная мера умственных усилий. [Проверка JSON](references/structured-results.md).

Код, схема JSON и машинные идентификаторы сохранены для совместимости. Текстовые пояснения в отчёте могут быть русскими. Промпты из русской книги повторены с адресом `skill-ru`; дополнительный запрос перед публикацией переведён из английского пакета.

# Проверка релиза

**Официальный исходный пакет Стандарта:** https://github.com/info-minimalism/skill  
**Русский перевод и обратная связь по нему:** https://github.com/info-minimalism/skill-ru  
**Версия Стандарта в установленном пакете:** 1.0.0

[Манифест релиза](../release.json) этого пакета фиксирует его версию. Одна установленная копия не доказывает, что это последняя опубликованная версия. Русский перевод относится к указанной версии исходного английского Стандарта; актуальность перевода и последняя опубликованная версия исходного Стандарта проверяются отдельно.

<a id="check-the-published-version"></a>
## Проверка опубликованной версии

Чтобы утверждать, что использована последняя версия, прочитайте текущий `release.json` официального исходного репозитория **https://github.com/info-minimalism/skill** через доступный разрешённый доступ на чтение. Манифест русского репозитория **https://github.com/info-minimalism/skill-ru** не заменяет эту проверку. Подтвердите, что исходный манифест объявляет `status: stable`, указывает версию и файл Стандарта и согласуется с версией и статусом в этом Стандарте. Зафиксируйте время получения и источник. Если есть более новая версия, получите и прочитайте применимые инструкции до оценки по ней либо сообщите, что установленный метод устарел. Не подменяйте незаметно обозначение версии.

Если русский перевод отстаёт от последнего стабильного исходного Стандарта, не утверждайте, что оценка по этому переводу проведена по последней версии. Можно дать результат по фиксированной переведённой версии с указанием ограничения либо, после прочтения необходимых исходных инструкций, провести оценку по новой английской версии и ясно назвать использованную версию и источник. Совпадение только номера версии перевода не заменяет проверки исходного манифеста и согласованности Стандарта.

Для обязательства проверять каждую публикацию используйте только стабильную опубликованную версию. Предварительный релиз, черновая ветка, предлагаемое изменение или временная метка установленного файла не являются последней опубликованной стабильной версией. Если репозиторий или Стандарт невозможно прочитать, метаданные противоречат друг другу либо стабильного релиза нет, отметьте проверку последней версии как недоступную и дайте только результат по фиксированной версии.

Для исторической проверки изучите историю релизов или датированный опубликованный снимок, показывающий, какая версия была актуальна в момент публикации. Сегодняшний манифест сам по себе не отвечает на этот вопрос. Если историю нельзя установить, укажите это ограничение. Старые оценки сохраняют исходные версии.

Чтение официальных метаданных релиза не разрешает устанавливать код, менять конфигурацию или публиковать. Если обновление требует установки, следуйте поддерживаемой агентом процедуре обновления с разрешением пользователя.

<a id="local-tests"></a>
## Локальные тесты

Метаданные релиза из тестового набора могут имитировать стабильный релиз только в явно обозначенном тесте. Укажите, что это тестовые данные, а не наблюдение действующего репозитория. Не используйте имитированные сведения о релизе в публичной записи оценки. Локальные результаты тестов не подтверждают фактическую публикацию или соблюдение обязательства издателем.
